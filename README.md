# 校務ポータル

職員がよく使う校務アプリ・共有フォルダ・Webサイトへのリンクを、スマートフォンのホーム画面のようにアイコンで並べたページです。
アイコンの下に、何のためのリンクかの説明が出ます。リンクは、担当の先生が追加・変更・削除できます。

## 置き方(担当の先生が最初に1回だけ)

1. このフォルダ(`portal`)を、校務共有サーバーの校務アプリのフォルダ(各アプリのフォルダと同じ場所)にコピーします。
   - 校務アプリへのリンクは「`../leave-manager/index.html`」のように、このフォルダから見た場所で書いてあるためです。
2. **Chrome または Edge** で `portal\index.html` を開き、「データファイルを作る」を押します。
3. 保存する場所を聞かれたら、**`index.html` と同じフォルダ**に、名前は **`links-data.js` のまま**保存します(名前を変えると、ページがリンクを読み込めません)。
4. 「✏ 編集する」を押し、編集用パスワード「0000」と名前を入れます。「⚙ 設定・バックアップ」で、**編集用パスワードを必ず変えてください**。ページの名前(例:〇〇中学校 校務ポータル)も変えられます。
5. 各職員のデスクトップに、`portal\index.html` へのショートカットを置きます。
   - ショートカットを開くブラウザが Chrome か Edge になっていることを確かめてください(既定のブラウザ)。

## 使い方(職員のみなさん)

- デスクトップのショートカットを開くと、リンクのアイコンが並びます。**アイコンを押すと、新しいタブで開きます**。
- 上の「さがす」に名前や説明の一部を入れると、当てはまるリンクだけが出ます。
- 共有フォルダのアイコンを押すと、**フォルダの場所がコピー**されます(ブラウザからはフォルダを開けないため)。エクスプローラーのアドレス欄に貼り付けて(Ctrl+V)、Enter を押してください。
- ファイルのアイコンは、担当の先生の設定によって、押すと **開く** か **ダウンロードされる** かが決まっています(アイコンの下に「ファイル(ダウンロード)」と出るものはダウンロード)。
  - 開くもの:PDF・画像はブラウザで表示、Excel・Word・PowerPoint はそれぞれのソフトで開きます(開いてよいかの確認が出たら「開く」を押してください)。それ以外のファイルは場所がコピーされます。
  - ファイルにも「📋 場所」のボタンがあり、場所をコピーできます。
- ほかの先生がリンクを直したときは「↻ 最新にする」を押すと、新しい内容が表示されます。
- はじめて開いたときは、画面の案内が出ます。もう一度見たいときは「❓ はじめての方へ」を押してください。

## リンクを追加・変更・削除する(担当の先生)

1. 「✏ 編集する」を押し、編集用パスワードと名前を入れます。
   - そのパソコンで初めて編集するときだけ、データファイルを選ぶ画面が出ます。このページと同じフォルダの `links-data.js` を選んでください。
2. 編集中は、アイコンの下にボタンが出ます。
   - **✎ 直す**:名前・説明・リンク先・アイコン・色を変える
   - **🗑**:削除する(確認のメッセージが出ます)
   - **並べ替え**:アイコンをつかんで、入れたい場所へ動かします。ほかの区分の「＋ リンクを追加」の所へ動かすと、その区分へ移せます。**◀ ▶** のボタンでも1つずつ動かせます
   - **＋ リンクを追加**:その区分にリンクを足す
   - 区分(「校務アプリ」「共有フォルダ」など)は、上の帯の「＋ 区分を追加」と、区分の名前の右のボタン(▲▼・名前・区分を削除)で直せます。
3. 変更は自動で保存されます。終わったら必ず「**編集を終える**」を押してください。
   - 編集中は、ほかの先生の画面に「○○先生が編集中」と出ます(2人で同時に直さないため)。

リンク先の決め方:

- **共有サーバーのファイル・フォルダ・校務アプリ**:リンクの画面の「📄 ファイルを選ぶ」「📁 フォルダを選ぶ」で選びます。校務アプリは、そのアプリの `index.html` を選びます。
  - そのパソコンで初めて選ぶときだけ、**共有サーバーの一番上のフォルダ**(Z ドライブなど)を選ぶ画面が出ます。リンクにするものは、このフォルダの中から選びます。ブラウザは、選んだファイルが「Z:\…」のどこにあるかを自分では知ることができないためです。
  - ポータルがそのフォルダの中にあれば、場所の書き方は自動で分かります。分からないときは、選んだフォルダの場所(例:`Z:\`)を聞かれるので、エクスプローラーのアドレス欄の書き方で入れてください。
  - 別のフォルダから選びたいときは「⚙ 設定・バックアップ」の「場所を登録し直す」を押します。
- **Webサイト**:リンク先の欄に `https://…` を貼り付けます。
- 手で書いてもかまいません(例:`Z:\様式集`、`\\サーバー名\共有\様式集`、`../leave-manager/index.html`)。「¥」で書いても「\」として読みます。
- ファイルを選んだときは「ファイルを押したとき」で **開く** か **ダウンロードする** かを選びます。様式など、各自がパソコンに保存して書き込むものは「ダウンロードする」が便利です。
- `Z:` などのドライブの文字は、職員のパソコンによって違うことがあります。違うパソコンがあるときは、`\\サーバー名\共有\…` の形で書いてください。

## データの保存場所

- リンクのデータは、`index.html` と同じフォルダの **`links-data.js`** に保存されます(校務共有サーバー)。
- サーバー名やフォルダの場所が入るので、インターネットやクラウドには置かないでください。
- ブラウザには、案内を見たかどうか・編集者の名前・前回選んだデータファイルの場所・リンク先を選ぶときの場所だけを覚えています。

## バックアップと復元

- **バックアップ**:「✏ 編集する」→「⚙ 設定・バックアップ」→「データを書き出す(バックアップ)」で、`校務ポータル_バックアップ_日付.json` がダウンロードされます。リンクを大きく直す前に取っておいてください。
- **復元**:同じ画面の「データを読み込む(復元)」で、バックアップのファイルを選びます。確認のメッセージのあと、今のリンクが置き換わります。
- `links-data.js` そのものを別の場所にコピーしておいても、バックアップになります。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 「データファイルが見つかりません」と出る | `links-data.js` が `index.html` と同じフォルダにあるか、名前が変わっていないか確かめてください。 |
| 編集できない・ボタンが押せない | Chrome か Edge で開いているか確かめてください。 |
| 「パスワードが違います」と出る | 担当の先生に聞いてください。 |
| 「○○先生が編集中」と出る | その先生が「編集を終える」を押すまで待ってください。15分たつと表示は消えます。 |
| 共有フォルダのアイコンを押しても開かない | 押すと場所がコピーされます。エクスプローラーのアドレス欄に貼り付けてください。 |
| 校務アプリやファイルのアイコンを押すと「ファイルにアクセスできません」と出る | 担当の先生が、リンクを「📄 ファイルを選ぶ」で選び直してください。手で書いたときは、場所の書き方(`Z:\…` など)が合っているか、そのパソコンにも同じドライブ(Z など)があるか確かめてください。 |
| Excel などのファイルが開かない | 「📋 場所」でコピーし、エクスプローラーのアドレス欄に貼り付けて開いてください。 |
| 「選んだファイルは、登録した場所の中にありません」と出る | 登録した場所(共有サーバーの一番上のフォルダ)の中から選んでください。別の場所なら「⚙ 設定・バックアップ」の「場所を登録し直す」を押します。 |
| リンクを間違えて消した | 「データを読み込む(復元)」で、バックアップから戻してください。 |

## 見本で試す

「データファイルを作る」の画面で「見本で試す」を押すと、架空のリンクで画面を試せます(見本は保存されません)。

## 後任の先生・開発者へ

- 仕組み・注意点・次にやることは [HANDOFF.md](HANDOFF.md)、変更の記録は [CHANGELOG.md](CHANGELOG.md) にあります。
- アイコンの候補や色の候補、初めに入れておくリンクは、`index.html` の先頭近くの「設定欄」で変えられます。
- 外部のライブラリは使っていません。
